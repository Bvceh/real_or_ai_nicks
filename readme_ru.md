# Real or AI?

Игра: угадай, какой ник — реальный, а какой сгенерирован нейросетью.

## Структура

```
client/           # веб-клиент (чистый HTML/JS)
  index.html      # игра
  players.csv     # реальные ники
  temp_0.*.txt    # сгенерированные ники по температурам 0.3–1.0
get_data.py       # сбор ников с серверов
train.py          # обучение char-level LSTM + генерация
```

## Запуск

**Собрать данные** (нужен `servers.txt` со списком `host:port`):
```bash
python get_data.py
```

**Обучить модель** (нужен `players.csv`):
```bash
python train.py
```

**Играть:** открыть `client/index.html` (можно через любой статический сервер, чтобы fetch подхватил `.csv`/`.txt`).

## Как работает

- `get_data.py` опрашивает серверы по протоколу A2S, собирает ники, фильтрует мусор и пишет `players.csv`.
- `train.py` учит посимвольную LSTM на реальных никах (8000 шагов, hidden=256), сохраняет `nicks.pt` и генерирует примеры при T=0.8 и T=1.0.
- Клиент грузит `players.csv` и `temp_*.txt`, чередует реальные и сгенерированные ники и показывает счёт.

## Настройки в игре

- Температуры генерации (0.3–1.0)
- Количество раундов (5/10/20)
- Язык RU/EN
