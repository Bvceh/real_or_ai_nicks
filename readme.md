# Real or AI?

A game: guess which nickname is real and which one was generated by a neural network.

## Structure

```
client/           # web client (plain HTML/JS)
  index.html      # the game
  players.csv     # real nicknames
  temp_0.*.txt    # AI-generated nicknames per temperature 0.3–1.0
get_data.py       # collect nicknames from servers
train.py          # train char-level LSTM + generate
```

## Usage

**Collect data** (requires `servers.txt` with a list of `host:port`):
```bash
python get_data.py
```

**Train the model** (requires `players.csv`):
```bash
python train.py
```

**Play:** open `client/index.html` (serve it through any static server so `fetch` can load the `.csv`/`.txt` files).

## How it works

- `get_data.py` queries servers over the A2S protocol, collects nicknames, filters noise, and writes `players.csv`.
- `train.py` trains a character-level LSTM on real nicknames (8000 steps, hidden=256), saves `nicks.pt`, and generates samples at T=0.8 and T=1.0.
- The client loads `players.csv` and `temp_*.txt`, alternates real and generated nicknames, and tracks the score.

## In-game settings

- Generation temperature (0.3–1.0)
- Number of rounds (5/10/20)
- Language RU/EN
